# FlowCast Lyrics 原生選項欄設計

## 目的

修正 FlowCast Lyrics 膠囊的設定面板不可用問題。AndroidLiquidGlass 保留為膠囊的視覺核心；設定互動改由 Windows 原生控制項處理，避免 Compose 視窗中的點擊、關閉與按鈕擠壓問題。

## 使用方式

1. 使用者右鍵點擊 FlowCast Lyrics 膠囊。
2. 右鍵選單顯示「調整玻璃」與「結束 FlowCast Lyrics」。
3. 選擇「調整玻璃」後，膠囊旁彈出無標題列的原生選項欄。
4. 選項欄提供圓角、模糊、折射高度、折射強度與色差開關。
5. 「重設」回到預設值；「取消」捨棄本次變更；「完成」套用並保存。

## 介面與文字

所有使用者可見字串必須為繁體中文：

- 右鍵選單：「調整玻璃」、「結束 FlowCast Lyrics」。
- 控制項：「圓角」、「模糊」、「折射高度」、「折射強度」、「色差」。
- 按鈕：「重設」、「取消」、「完成」、「關閉」。
- 連線狀態：「正在尋找 FlowCast」、「已連線，等待歌詞」。

選項欄為約 320px 寬的直式浮動欄。底部按鈕必須各自保持完整的一行文字，不得因欄寬壓縮換行。它沒有 Windows 一般視窗的標題列或工作列項目，並定位在膠囊附近；若螢幕邊界不足，改放到膠囊可見的一側。

## 架構

- Kotlin Compose / AndroidLiquidGlass：只維持膠囊、外觀、位置及右鍵命令事件。
- AudioShare.Lyrics WPF 主程式：建立、顯示、關閉與定位原生選項欄；接收暫存設定，並在完成時送回既有的 `settings-committed` 管線。
- 既有設定儲存：沿用 `LyricsGlassSettingsStore` 與 `LyricsGlassHostStatePersistence`。只有完成時才寫入。

不修改 Radmin VPN 探索、連線協定、即時歌詞來源或 FlowCast 主程式的音訊路由。

## 原生操作入口

Compose 的右鍵事件在此 Windows 環境不可靠，因此膠囊不再負責接收滑鼠操作。WPF 主程式建立與膠囊同位置、同尺寸的原生透明輸入層：左鍵拖曳時更新膠囊位置；右鍵時顯示 Windows 原生選單「調整玻璃／結束 FlowCast Lyrics」。選單命令直接開啟原生選項欄或結束主程式。輸入層不得繪製任何可見內容，AndroidLiquidGlass 的視覺外觀維持不變。

## 狀態與錯誤處理

- 重新開啟選項欄時，從目前已保存設定開始。
- 取消或關閉選項欄時，不送出設定變更。
- 膠囊結束時，選項欄一併關閉。
- 選項欄無法建立時，保留膠囊與右鍵選單，且不得讓 FlowCast Lyrics 卡死或無法結束。

## 驗證

1. 自動測試驗證：開啟選項欄、取消不保存、完成才保存、結束膠囊會關閉選項欄。
2. 建置驗證：Lyrics 專案與完整方案測試通過。
3. Windows 實機驗證：從 `D:\DIOWMOW\Documents\音樂\FlowCast Lyrics` 開啟，右鍵膠囊、開啟選項欄、修改一個滑桿、完成、重新開啟後確認設定保留，並能正常結束。
